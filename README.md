# Rangkai

A responsive, interactive wireframe for learning Malay through a small vocabulary pool and repeated sentence patterns, inspired by the gradual expansion of keybr.

## Try it

Open `index.html`, or serve the repository:

```sh
python3 -m http.server 8000 --directory /workspace/learn-malay
```

No build, package installation, backend, or API key is required. The app uses plain HTML, CSS, and JavaScript. Google Fonts are optional; system fonts are the fallback.

## Learning flow

1. Start with five subjects, five verbs, and four everyday objects.
2. Guess a sentence's meaning, then reveal a curated explanation. Tap words for usage notes.
3. Build sentences from word tiles and compare grammar patterns.
4. Self-rate five distinct sentences as familiar to unlock the next chapter: `sedang`, standard `meN-` verb forms, then two new objects.
5. Revisit difficult sentences using the review queue. Progress persists in localStorage on the same browser/device.

The prototype has 20 curated sentences and four pattern comparisons. Self-ratings demonstrate the progression concept; they are not a mastery assessment. Free-text guesses are not graded. Explanations are not generated by AI.

Malay `meN-` forms do not themselves express an ongoing action. The lessons separate those forms from the aspect marker `sedang`, and distinguish conversational root verbs from standard active forms. This is a small demonstration curriculum, not a complete affix reference.

## Publication

The `gh-pages` branch contains the static site. Configure GitHub Pages to deploy from `gh-pages`, directory `/ (root)`. Relative asset links support hosting under `/learn-malay/`.
